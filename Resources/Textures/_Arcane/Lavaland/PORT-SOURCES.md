# Lavaland artwork

The RSI directories in this folder are unchanged copies of the artwork at [Goob Station revision cc1d2c911f5cb6c90b36e0899ce918010bd41262](https://github.com/Goob-Station/Goob-Station/tree/cc1d2c911f5cb6c90b36e0899ce918010bd41262). Each `meta.json` retains the original credits and license.

- [Goob #6520](https://github.com/Goob-Station/Goob-Station/pull/6520) and [Goob #6605](https://github.com/Goob-Station/Goob-Station/pull/6605) provide the flora, flowers, planks, cudgels, pickaxes and upgraded plasma cutter. The metadata identifies Engenia/Jaraten, MisterMecky, RedTerror and the individual upstream asset sources.
- Sticks, the upgraded mining drill and the ashwood log reuse existing project artwork or the imported ashwood planks. The new forest ground tile reuses the existing grass texture.
