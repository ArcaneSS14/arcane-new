# Folded uniform sprites

Source: [Goob-Station/Goob-Station](https://github.com/Goob-Station/Goob-Station), commit
`cc1d2c911f5cb6c90b36e0899ce918010bd41262`, folding feature introduced in
[#6160](https://github.com/Goob-Station/Goob-Station/pull/6160).

The directories below retain only the compatible `folded-equipped-INNERCLOTHING`
states and their supplied species variants. PNG bytes are unchanged. Each
`meta.json` retains the source size, license, full copyright/author description
and other metadata, with its state list restricted to the accompanying files.

All included RSI metadata declares **CC-BY-SA-3.0**. Original artists and upstream
SS13 repository revisions remain recorded in each corresponding `meta.json`.
Keep those notices with the images; this directory does not replace them with a
single new author or license.

Arcane supplies a separate worn-visual consumer and keeps the existing uniform's
normal, icon and in-hand artwork. Variants lacking a compatible complete set of
ready folded frames receive no folding behavior. No new sprites were drawn or
recolored for this subset.
