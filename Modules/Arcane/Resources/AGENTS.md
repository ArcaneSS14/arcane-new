# Arcane resource guidance

This directory currently holds guidance rather than Arcane runtime resources. Arcane-owned resources live in the existing `_Arcane` directories under the repository's root `Resources` tree; verify the exact owner path before adding a resource.

Keep paths consistent with the existing resource tree. Update every prototype, locale, sprite-state, and audio reference when moving a resource. Validate YAML and RSI metadata. Preserve source attribution and asset-specific licensing.

Do not create a parallel `Modules/Arcane/Resources` hierarchy.
