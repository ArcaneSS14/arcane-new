# Factory module guide

Factory is an extension module for machinery and automation. Its four root projects split shared contracts, server authority, and client presentation; project directories remain at the repository root.

## Mechanics present

- Circuits and circuit editing, including circuit housings and signal payloads.
- Filters and automated item routing, with filter slots and client filter UI.
- Plumbing and machine connections.
- Machine construction and interaction, including constructors and robotic-arm presentation.
- Device linking and clocks, access scanners, power, lighting, radio, fax, and signal screens.
- Automation for atmos filters and lathe systems.

The project-specific guides under this directory show which layer owns each implementation, with source-directory links and representative files. Consult [`CATALOG.md`](../CATALOG.md) for project references and build impact. Resources/prototypes are not fully represented by the C# source map.
