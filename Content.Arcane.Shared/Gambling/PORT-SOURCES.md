# Off-duty port sources

Adapted from Goob-Station/Goob-Station, revision `cc1d2c911f5cb6c90b36e0899ce918010bd41262`.

- [Gambling, #7092](https://github.com/Goob-Station/Goob-Station/pull/7092), JohnJJohn: slots, CoinFlipper, ClawMachine, prize tables, machine resources and supplies.
- [Cards, #6507](https://github.com/Goob-Station/Goob-Station/pull/6507), coookies369: playing cards and their resources, using the pinned EstacaoPirata-derived implementation as the behavioral reference. The source English card text also credits Aiden, RadsammyT and coderabbitai[bot]; these are upstream credits, not new service signatures.
- [Tennis, #6469](https://github.com/Goob-Station/Goob-Station/pull/6469), [supply, #6497](https://github.com/Goob-Station/Goob-Station/pull/6497), and [ball correction, #6833](https://github.com/Goob-Station/Goob-Station/pull/6833), Hardbassman.
- [Radio remainder, #7176](https://github.com/Goob-Station/Goob-Station/pull/7176), JohnJJohn: general sound specifiers and missing vinyl variants. Existing Trauma playback, power, device links, radio roles and CopyrightedAudio marking are retained.

Source code is licensed under AGPL-3.0-or-later according to the source repository and cached file headers. Arcane adaptations by UmbiMax use the current interaction, DoAfter, stacks, entity tables, achievements, storage, chemistry and audio owners. Hidden cards are server records; public entities reveal only permitted surfaces, and hand menus are addressed to the current holder. Joker effects use native server-only components and a native direct solution with regeneration. Existing plushie tables replace unavailable personal Claw rewards; personal Voodoo behavior is outside this package.

previously unresolved. This declaration is separate from the independently
